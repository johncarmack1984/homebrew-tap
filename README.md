# homebrew-tap

Homebrew tap for [glslint](https://github.com/johncarmack1984/glslint) — a luma.gl/deck.gl-aware GLSL checker and language server.

```sh
brew install johncarmack1984/tap/glslint
```

This installs a prebuilt binary and pulls in `glslang` (for `glslangValidator`) as a dependency. `brew upgrade` tracks new releases.

`Formula/glslint.rb` is generated by [`homebrew/prepare.mjs`](https://github.com/johncarmack1984/glslint/blob/main/homebrew/prepare.mjs) in the glslint repo and pushed here by its release workflow on every release. Do not edit it by hand.
